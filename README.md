# adaptive-vla-post-training

pi0.5 training for the single-arm Franka FR3 + AgileX gripper cooking rig.

* **[`VLA-Adaptation/pi05_training/`](VLA-Adaptation/pi05_training/README.md)** trains pi0.5
  from `pi05_base` on the RSM cooking demonstrations with unmodified upstream OpenPI. It
  follows the recipe of sunshine's h50/canonical run, with discrete state input.
